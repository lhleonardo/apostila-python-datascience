# Módulo 5 — Limpeza de Dados

Com o essencial de Pandas dominado (Módulo 4), é hora de encarar de frente
algo que ocupa a maior parte do tempo real de quem trabalha com dados:
**dados sujos**. Datasets do mundo real vêm com valores ausentes, duplicados,
tipos errados, texto inconsistente ("SP", "São Paulo", "sao paulo" querendo
dizer a mesma coisa) e valores absurdos que não deveriam estar ali. Antes de
analisar ou tirar qualquer conclusão, é preciso limpar.

Este módulo aprofunda o que foi visto de leve no Tópico 11 do Módulo 4
(valores ausentes) e adiciona as outras frentes de limpeza mais comuns:
duplicatas, tipos de dados, texto inconsistente, datas e outliers.
