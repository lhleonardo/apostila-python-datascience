# Módulo 7 — Visualização

Você já sabe resumir dados em números (Módulo 6) — agora é hora de resumir
em **imagens**. Um bom gráfico comunica um padrão em segundos, algo que uma
tabela de números exigiria minutos de leitura atenta para perceber. Este
módulo ensina a construir gráficos com Matplotlib (a biblioteca de
visualização mais fundamental do ecossistema Python) e Seaborn (construída
em cima dela, com gráficos estatísticos prontos e visual mais elegante por
padrão).

O objetivo não é decorar toda a API de nenhuma das duas bibliotecas — é
saber escolher o gráfico certo para cada pergunta e construí-lo sem lutar
contra a ferramenta.
