# Módulo 1 — Fundamentos de Python

Neste módulo você vai aprender a base da linguagem Python: como escrever e
rodar código, os tipos de dados fundamentais, como tomar decisões e repetir
tarefas com o código, e como organizar dados em listas, dicionários e outras
estruturas. Tudo isso usando como pano de fundo os dados de vendas de uma
pequena loja fictícia, a "Loja da Ana".

Ao final deste módulo você será capaz de escrever pequenos programas Python do
zero, sem depender de nenhuma biblioteca externa.
