# Python para Análise de Dados — Apostila

Esta apostila foi criada para levar alguém sem experiência profunda em
programação — mas que já sabe o básico de Python (variáveis, tipos,
condicionais, loops, listas e dicionários) — até um nível intermediário/avançado
de análise de dados com Python.

O foco é **aprender fazendo**. Cada tópico tem explicação curta, exemplo
comentado, erros comuns, exercício prático e solução comentada. Não é
necessário decorar nada: o objetivo é entender o suficiente para resolver o
exercício e seguir em frente.

## Como usar esta apostila

- Siga os módulos **na ordem**. Cada um assume que você já sabe o conteúdo dos
  anteriores.
- Dentro de cada módulo, siga os tópicos na ordem numerada.
- Não pule o exercício prático. É nele que o conceito realmente gruda.
- Se travar em algum exercício, releia a seção "Como funciona" do tópico antes
  de abrir a solução.
- Ao final de cada módulo, use o checklist do último tópico para decidir se
  está pronto para avançar.

## Sobre os dados usados nos exemplos

Para dar sensação de continuidade, os módulos 1 e 2 usam como pano de fundo uma
**loja fictícia** (a "Loja da Ana"), com dados de vendas simples. A partir do
módulo 4, quando começamos a usar pandas, também aparecem datasets públicos
reais (sempre com uma versão inline de backup, caso você não consiga baixar
nada).

## Pré-requisitos

- Python instalado (o Módulo 1, tópico 2, ensina isso).
- Vontade de errar bastante — é assim que se aprende a programar.
