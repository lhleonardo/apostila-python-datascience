# Módulo 3 — NumPy

Com Python "puro" e as ferramentas de ambiente dominadas (Módulos 1 e 2),
chegou a hora da primeira biblioteca de dados de verdade: **NumPy**. Ela é a
base sobre a qual o Pandas (Módulo 4) e praticamente todo o ecossistema
científico de Python são construídos — entender bem NumPy torna tudo que vem
depois muito mais fácil.

Deixamos a "Loja da Ana" de lado por um momento: NumPy trabalha com números em
massa (preços, quantidades, medições), então os exemplos aqui usam dados
numéricos mais diretos — nos módulos seguintes voltamos a aplicá-los a
contextos de negócio.
