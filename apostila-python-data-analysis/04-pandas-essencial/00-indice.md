# Módulo 4 — Pandas Essencial

Com NumPy no repertório (Módulo 3), chegou a hora do **Pandas** — a
biblioteca que profissionais de dados usam no dia a dia para carregar,
explorar, filtrar, transformar e resumir tabelas de dados. Pandas é
construído em cima do NumPy: uma coluna de um DataFrame é, por baixo, um
array NumPy — então tudo que você aprendeu no Módulo 3 (vetorização,
broadcasting, boolean masking) continua valendo aqui, só que aplicado a
tabelas com nomes de coluna e rótulos, não apenas números soltos.

A partir daqui, além da "Loja da Ana", os exemplos também usam **datasets
públicos reais** (sempre com uma versão inline de backup no próprio tópico,
caso você não consiga baixar nada) — é hora de praticar com dados do jeito
que eles aparecem no mundo real: um pouco bagunçados, com colunas demais e
nem tudo do jeito que você gostaria.
