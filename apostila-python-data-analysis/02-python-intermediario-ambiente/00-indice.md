# Módulo 2 — Python Intermediário e Ambiente

Com os fundamentos da linguagem em mãos (Módulo 1), este módulo fecha o
conhecimento de Python "puro" que falta antes de entrarmos em bibliotecas de
dados (NumPy e Pandas), e te apresenta as ferramentas de ambiente que
profissionais de análise de dados usam no dia a dia: como instalar pacotes,
isolar projetos e trabalhar em notebooks interativos.

Continuamos usando a "Loja da Ana" como fio condutor, mas agora ela vai
guardar dados em arquivos (JSON, CSV) e ganhar um pouco mais de estrutura com
classes.
